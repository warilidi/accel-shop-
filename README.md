# Accel Shop Bot

Telegram-бот магазина подписок с категориями:
- `Нейросети`
- `Другие сервисы`

Реализовано:
- каталог и вложенные кнопки (раздел -> сервис -> товар);
- карточка товара с коротким описанием типа (`ACC`, `CDK`, `Link` и т.д.);
- выбор количества (от 1 до доступного остатка);
- оплата: `CryptoBot USDT`, `CryptoBot TON`, `Bybit`;
- формат заказа как в примере с временем оплаты 15 минут;
- **автоматическая проверка оплаты** через CryptoBot API (создание реальных инвойсов, фоновая проверка статуса, автовыдача товара);
- кнопка «Проверить оплату» для ручной проверки статуса инвойса;
- выдача товара после подтверждения оплаты;
- админ-функции:
  - добавление нового товара вручную;
  - добавление "единиц выдачи" (логины/ключи/данные);
  - изменение остатка;
  - рассылка по покупателям.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN`
- `ADMIN_IDS`
- `BYBIT_UID`
- `CRYPTOBOT_API_TOKEN` — токен CryptoBot API для автоматической проверки оплаты
- `PAYMENT_CHECK_INTERVAL` — интервал проверки оплаты в секундах (по умолчанию 30)
- `CHANNEL_ID` — числовой ID канала для обязательной подписки (например, `-1001234567890`)
- `CHANNEL_USERNAME` — юзернейм канала без @ (например, `Accel_Shop`)
- ссылки и курс USD/RUB

## Автоматическая проверка оплаты

Если указан `CRYPTOBOT_API_TOKEN`:
1. При выборе оплаты через CryptoBot создаётся **реальный инвойс** через API
2. Фоновая задача каждые `PAYMENT_CHECK_INTERVAL` секунд проверяет статус всех ожидающих инвойсов
3. При обнаружении оплаты товар **автоматически выдаётся** пользователю
4. Пользователь может нажать кнопку «Проверить оплату» для мгновенной проверки

Если `CRYPTOBOT_API_TOKEN` не указан — используется старая схема с шаблонными ссылками и ручным подтверждением.

## Запуск

```bash
python -m app.bot
```

## Админ-команды

- `/admin` - список команд
- `/additem` - добавить товар вручную
- `/addpayload <product_id> | <данные>` - добавить 1 товарную единицу
- `/setstock <product_id> <qty>` - установить остаток
- `/broadcast` - рассылка
- `/order <код>` - проверка заказа
