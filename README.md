# Accel Shop Bot

Telegram-бот магазина подписок с категориями:
- `Нейросети`
- `Другие сервисы`

Реализовано:
- каталог и вложенные кнопки (раздел -> сервис -> товар);
- карточка товара с коротким описанием типа (`ACC`, `CDK`, `Link` и т.д.);
- выбор количества (от 1 до доступного остатка);
- оплата: `CryptoBot USDT`, `CryptoBot TON`, `Bybit`;
- формат заказа как в примере с временем оплаты 15 минут;
- выдача товара после подтверждения оплаты (`✅ Я оплатил`);
- админ-функции:
  - добавление нового товара вручную;
  - добавление "единиц выдачи" (логины/ключи/данные);
  - изменение остатка;
  - рассылка по покупателям.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN`
- `ADMIN_IDS`
- `BYBIT_UID`
- ссылки и курс USD/RUB

## Запуск

```bash
python -m app.bot
```

## Админ-команды

- `/admin` - список команд
- `/additem` - добавить товар вручную
- `/addpayload <product_id> | <данные>` - добавить 1 товарную единицу
- `/setstock <product_id> <qty>` - установить остаток
- `/broadcast` - рассылка
- `/order <код>` - проверка заказа

## Важно по оплате

Сейчас для `CryptoBot` используется шаблонная ссылка `https://t.me/CryptoBot?start=invoice-...`.
Чтобы сделать полностью автоматическое создание инвойсов и авто-подтверждение оплаты, нужно подключить API CryptoBot (токен/merchant), после чего можно дополнить обработку статусов платежа.
